# Bulanık Mantık Dönem Projesi

Bu projede bulanık mantık kullanılarak akıllı klima kontrol sistemi geliştirilmiştir.

## Kullanılan Teknolojiler
- Python
- scikit-fuzzy
- numpy
- matplotlib
- streamlit

## Özellikler
- Giriş değerlerini değiştirme
- Üyelik fonksiyonlarını gösterme
- Aktif kuralları listeleme
- Grafiksel sonuç gösterimi
